# Fókusz launcher

Saját, minimál Android kezdőképernyő: analóg óra, hat app szövegként, kintsugi háttér, lassított indítás a figyelemelterelő appokra és esti Csend mód.

**Letöltés:** a legfrissebb APK mindig itt van:
`https://github.com/mickey01732-crypto/fokusz-launcher/releases/latest/download/fokusz-launcher.apk`

## Használat

- **Koppintás** egy appnévre: megnyitja.
- **Hosszan nyomva** egy appnévre: lecserélheted, mi legyen a helyén.
- **Felfelé húzás:** összes app és keresés.
- **Lefelé húzás:** értesítések.
- **Hosszan nyomva az órán vagy üres helyen:** beállítások (Csend mód, időpontok, háttérkép).
- **Összes app → hosszan nyomva egy appon:** korlátozás be/ki (10 mp szünet indítás előtt), app infó, eltávolítás.
- **Csend mód** (alapból 22:00–6:30): a kezdőképernyő helyén a 静 jel. Feloldható 10 percre.
